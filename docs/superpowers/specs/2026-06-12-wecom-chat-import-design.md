# 企业微信转发聊天记录导入工具

## 背景

用户的朋友通过企业微信与客户沟通，聊天记录中大量是语音消息。朋友开启企业微信"语音自动转文字"功能后，在 PC 端全选复制聊天记录到 txt 文件。该 txt 文件包含文字消息和语音转文字内容，需要导入 RAG 知识库。

## 目标

扩展 `pipeline/chat_importer.py`，支持解析企业微信转发聊天记录格式。

## 格式对比

### 现有格式（企业微信导出 txt）
```
2026-06-09 14:49:03 客户-Will
抖音账号检测在哪里？

2026-06-09 14:49:13 销售-朱廷帅
在抖音的创作者中心里...
```

### 新格式（企业微信 PC 端复制）
```
Will@微信@微信联系人 6/9 14:49:03
抖音账号检测在哪里？

朱廷帅 6/9 14:49:13
在抖音的创作者中心里...
```

## 设计

### 格式检测

自动检测文件格式：匹配 `^\d{4}-\d{2}-\d{2}\s` 为现有格式，匹配 `^.+@\S+\s+\d{1,2}/\d{1,2}\s` 为新格式。

### 新格式解析

- **正则**：`^(.+?)\s+(\d{1,2}/\d{1,2}\s+\d{2}:\d{2}:\d{2})$`
- **角色判断**：发言人含 `@微信` → 客户，否则 → 销售
- **日期补全**：`MM/DD` 补全年份（从文件名或当前年份推断）

### 改动文件

1. `pipeline/chat_importer.py` — 新增 `WECOM forwarded` 格式的正则和解析逻辑，`parse_chat_file()` 自动检测格式
2. 无需新增文件

### 不变

- QAPair 数据结构不变
- chunker → embedder → Qdrant 流程不变
- 现有格式的解析逻辑不变

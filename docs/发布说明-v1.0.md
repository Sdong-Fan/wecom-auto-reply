# v1.0 — Windows 免安装版

> 这是「截图 RPA + 资料库 RAG」自动客服的**免安装分发包**：解压即用，不需要装 Python。

## 这是什么

给"一个人兼客服的 1–5 人小店"用的自动客服：截屏 + OCR 读企业微信消息，**只按店主自己上传的资料回答**，
价格 / 型号在资料里查不到就**转人工**，人工改稿确认后它还会学。

本项目**基于开源项目 [zhu-tingshuai/personal_wxwork_ZTS](https://github.com/zhu-tingshuai/personal_wxwork_ZTS)（MIT）改造**；
采集层（截图 / 红点 / 气泡 / OCR）与界面框架来自上游，改造部分见仓库 README「项目来源与我的改造」。

## 怎么用（3 步）

1. 下载 `WeComBot-v1.0-win64.zip` → 解压到任意目录（**路径别太深，别放中文路径的奇怪位置**）
2. 双击 **启动.bat**（首次启动要加载 OCR 与向量模型，约 30~90 秒，请耐心等）
3. 界面右上「**设置**」→ 填**你自己的**模型接口（`API Key` / 接口地址 / 模型名）→ 保存；
   然后选「企业微信 · 截图模式」→ 打开企业微信 PC 版并登录 → 点「**开始**」

> **不填 Key 也能开**：此时机器人不会自动回复，只把消息转进「待人工」，**不向任何地方外发内容**。
>
> 详细步骤（含资料库用法、提示词、API 模式、常见问题排错）见包内 **`使用说明-详细.md`**；
> 简版见 `使用说明.txt`。

## 运行要求

* Windows 10 / 11 64 位
* 企业微信 PC 版（截图模式）；微信 PC 版需先用 `scripts/calibrate_chat_app.py` 标定
* 一个 OpenAI 兼容的模型接口（DeepSeek / 通义 / 本地 vLLM 皆可）
* 客户端改版或缩放 / 分辨率变化后，需要重新标定 `profiles/`
  （发送前会确认会话名，标定不对时会跳过这一行，而不是发错人）
* 首次启动需加载 OCR 与本地嵌入模型，约 30~90 秒

## 包里有什么

* `启动.exe` + `_internal/`：Python 运行时、OCR（RapidOCR/ONNX）、本地嵌入模型（bge-small-zh）
* `prompts/`：提示词（可改说话方式）
* `profiles/`：窗口标定
* `data/qdrant/`：**内置示例资料库**（虚构的相机租赁业务，可先试跑）
* `data/chat_raw/`：示例资料原文（14 份 txt）
* `使用说明.txt` / `使用说明-详细.md`

## 包里**没有**什么（隐私）

打包流程带**强制隐私门禁**（`scripts/privacy_check.py`），以下内容**不会**进包：

* `.env`（任何密钥）、客户聊天记录、运行状态、日志、开发机路径

客户聊天记录只存在你自己机器的 `data/context/`；回答时只把「客户这一句话 + 命中的资料片段」
发给**你自己配置的**模型接口。不配 Key 则完全不外发。

## 合规提醒

本项目通过**模拟人工操作**控制桌面客户端。请确认这符合你所在平台的服务条款与当地法律；
请只在自己的账号、自己的客户范围内使用，并遵守关于聊天记录处理的规定。

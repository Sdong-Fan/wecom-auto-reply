# v1.1 — Windows 免安装版

> 这是「截图 RPA + 资料库 RAG」自动客服的**免安装分发包**：解压即用，不需要装 Python。

## 这是什么

给"一个人兼客服的 1–5 人小店"用的自动客服：截屏 + OCR 读企业微信消息，**只按店主自己上传的资料回答**，
价格 / 型号在资料里查不到就**转人工**，人工改稿确认后它还会学。

本项目**基于开源项目 [zhu-tingshuai/personal_wxwork_ZTS](https://github.com/zhu-tingshuai/personal_wxwork_ZTS)（MIT）改造**；
采集层（截图 / 红点 / 气泡 / OCR）与界面框架来自上游，改造部分见仓库 README「项目来源与我的改造」。

## 怎么用（3 步）

1. 下载 `WeComBot-v1.1-win64.zip` → 解压到任意目录（**路径别太深，别放中文路径的奇怪位置**）
2. 双击 **启动.bat**（首次启动要加载 OCR 与向量模型，约 30~90 秒，请耐心等）
3. 界面右上「**设置**」→ 填**你自己的**模型接口（`API Key` / 接口地址 / 模型名）→ 保存；
   然后选「企业微信 · 截图模式」→ 打开企业微信 PC 版并登录 → 点「**开始**」

> **不填 Key 也能开**：此时机器人不会自动回复，只把消息转进「待人工」，**不向任何地方外发内容**。
>
> 详细步骤（含资料库用法、提示词、API 模式、常见问题排错）见包内 **`使用说明-详细.md`**；
> 简版见 `使用说明.txt`。

## 运行要求

* Windows 10 / 11 64 位
* 企业微信 PC 版（截图模式）；微信 PC 版需先用 `scripts/calibrate_chat_app.py` 标定
* 一个 OpenAI 兼容的模型接口（DeepSeek / 通义 / 本地 vLLM 皆可）
* 客户端改版或缩放 / 分辨率变化后，需要重新标定 `profiles/`

## v1.1 改了什么

### 1. 修掉一个"客户完全收不到回复"的发送 bug（最重要）

发送时按窗口标题找目标窗口，而**机器人自己的界面标题也叫「企业微信智能客服」** ——
z-order 在最前时它把回复粘进了自己的界面，客户端一条都收不到。
现在改为按**进程名 + 窗口类**找窗口（扫描一直在用这套，稳定）。

### 2. 自动发门槛从 0.55 降到 0.50（多自动答、风险不变）

两条独立证据：46 题评测集扫描（0.50 符合 42/46，0.55 是 41/46）；
三批各 200 条共 600 条实测（0.50 符合 560/600，0.55 是 550/600）——**两种阈值危险直发都是 0**。

### 3. 新增一组"安全护栏"（降门槛的前提）

| 护栏 | 拦的是什么 |
| :--- | :--- |
| 越权承诺 | 回复里出现 有货 / 给你留着 / 两小时后就能到 / 来得及 / 保证 → 转人工（库存、留货、时效只有店主能承诺） |
| 拖延话术 | 回复里"这块得跟店里确认下，晚点回你" → 转人工（不能让客户干等，人工却不知道） |
| 议价加码 | "再便宜点 / 按老客户价 / 批发价 / 定金能少点 / 多给点赠品" → 转人工（机器人无权改价） |
| 资料未覆盖政策 | 电子发票 / 个人抬头 / 13% / 补开 / 三方合同 / 保价 / 指定到小时 / 信用卡预授权 → 转人工 |
| 投诉与纠纷 | 投诉 / 退款 / 议价 / 订单变更 / 找人 / 重复追问 → 不看检索分，直接转人工 |
| 指代不明与库存档期 | "那个多少钱""还有别的选择吗""国庆有货吗""能给我留着吗" → 转人工 |
| 无信息量消息 | 纯符号 / 纯数字 / 纯表情 → 不回（不再回"哈哈这是啥，密码吗"） |
| 越界与隐私 | 套提示词 / base64 注入 / 管理员身份 / 导出配置 / 伪造材料 / 索要他人信息 → 固定模板婉拒 |

### 4. 补齐的细节

* 收尾语补上"好嘞 / 谢啦 / 知道了"这类，不再被当成问题去回
* 型号别名归一：「GM2」与资料里的「GM II」视为同一个型号（原来会误判成编造型号）
* 暖场寒暄（"你们辛苦了""你叫什么名字""你能听懂粤语吗"）不再被当成业务问题转人工

## 测试与评测资产

* 自动化测试 **1341 个**（含"发错人""内部信号外泄""编造型号""承诺越权"等事故的回归测试）

## 合规说明

  发给使用者自己配置的模型接口。

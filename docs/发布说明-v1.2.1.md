# v1.2.1 — Windows 免安装版（修复版）

> 「截图 RPA + 资料库 RAG」自动客服的**免安装分发包**：解压即用，不需要装 Python。
> **这一版是 v1.2 的修复版**，只修 bug、不加功能 —— 已经装了 v1.2 的话直接覆盖解压即可（`data/` 目录自己留着）。

## 这是什么

给"一个人兼客服的 1–5 人小店"用的自动客服：截屏 + OCR 读聊天软件里的消息，
**只按店主自己上传的资料回答**，价格 / 型号在资料里查不到就**转人工**，
人工改稿确认后它还会学（**学习功能出厂默认关闭**，见下方说明）。

本项目**基于开源项目 [zhu-tingshuai/personal_wxwork_ZTS](https://github.com/zhu-tingshuai/personal_wxwork_ZTS)（MIT）改造**；
采集层（截图 / 红点 / 气泡 / OCR）与界面框架来自上游，改造部分见仓库 README「项目来源与我的改造」。

## 怎么用（3 步）

1. 下载 `WeComBot-v1.2.1-win64.zip` → 解压到任意目录（**路径别太深**）
2. 双击 **启动.bat**（首次启动要加载 OCR 与向量模型，约 30~90 秒）
3. 界面右上「**设置**」→ 填**你自己的**模型接口（API Key / 地址 / 模型名）→ 保存；
   然后选接入通道 → 打开对应软件并登录 → 点「**开始**」

> **没配模型接口就不能「开始」**：点「开始」会被拦下并弹窗送你到「设置」（界面顶部也会常显提示）。
> 原因：没配接口时它答不了业务问题，**却仍会给客户回一句"稍等，我帮您确认一下"**
> —— 没人处理「待人工」就等于替老板许了个空头承诺。程序默认就是「未启动」，打开后什么都不做。
>
> 详细步骤（资料库用法、提示词、API 模式、常见问题排错）见包内 **`使用说明-详细.md`**。

## v1.2.1 修了什么

这一版的四个问题都是**使用者实机测试报上来的**，不是自查发现的。

### 1. 密钥框里那串"已经填好的密钥"是假的 —— 现在会留空

第一次运行 `启动.bat` 时，脚本会把 `.env.example` 复制成 `.env`，而示例文件里写着
`DEEPSEEK_API_KEY=sk-your-deepseek-key`。原来的代码把它当成真密钥，于是：

* 设置面板的密钥框里显示一串点，**看着像已经配好了**（实际是 20 个字符的占位符）
* 更麻烦的是程序会拿它去调模型接口，只会拿到 401，而界面上看不出哪里不对

现在：占位符一律当**没填**（密钥框留空），程序按"不填 Key 也能开"的既定行为走
（只转人工、不外发任何内容）。点「测试连接」会明确说"现在填的是示例里的占位符，不是真密钥"。

> 顺带说明：**发布包里从来没有真实密钥**。包里只有 `.env.example`（占位符版），
> 真密钥不存在于压缩包、也不存在于仓库任何一次提交里。

### 2. 「测试连接」按钮点了直接报错

报 `TypeError: cannot unpack non-iterable coroutine object`。
原因是连通性测试函数是异步的，界面这层没等它就被拆包了 ——
**既报错，测试请求其实也从没发出去**。现在会正常跑完并给出结论
（通了 / 401 密钥不对 / 404 模型名不对 / 地址不通）。

### 3. 「预设」下拉框是一片空白

模型服务商预设（DeepSeek 官方 / OpenRouter / 通义 / Kimi / 硅基流动）**文字和下拉箭头都没画出来**，
只剩一个空框，等于这个功能看不见。现在正常显示，并且灰底改成和旁边输入框一致。

### 4. 配置文件只认程序自己目录下的 `.env`

原来程序会从所在目录**一路往上找** `.env`。如果把它解压到某个本身就带 `.env` 的目录里，
它会静默读走那份**不相干的密钥**并拿去调接口。现在只认自己目录下的 `.env`，没有就当没配。

设置面板现在还会显示**配置文件的完整路径**，方便确认"这个密钥是从哪读的"。

### 5. 更正了"没填 Key 会怎样"的说明，并改成**没配 Key 不允许开始**

原来说明书写的是"不填 Key 时机器人**不会自动回复**"—— 实测**不成立**：
有三类消息根本不需要联网调模型就会发给客户（时间类问题直接答、越界请求按模板婉拒、
**每个答不了的问题都回一句固定占位语**）。只有"不把内容发到模型接口"这一句是对的。

既然它会照常回客户，那"没配 Key 也能开着"这个说法本身就是坑：
店主以为没事、挂着不管，客户却被许诺了一个不会到来的回复。

所以现在改成：**没配模型接口就不让「开始」** —— 点「开始」会弹窗说明原因并直接打开「设置」，
界面顶部也常显红字提示（`WECOM_AUTOSTART=1` 脚本化启动同样会被拦下）。
文档按实测改写，"想先观察就看别点开始"（程序默认就是未启动）。

### 6. 「从人工改稿学习」——出厂默认关闭

**这是有意的**：学习会往本机写文件（语气规则 / 口吻样本 / 待确认的说法），
不该在店主还没弄明白它学什么之前就悄悄开始。

* 想开启：**「知识库」→「学到的」页 → 勾上「自动学习」**（开关写回 `config.json`，重启也记得）
* 开启后**只自动学「怎么说话」**（语气规则、口吻样本）；
  人工回复里带出的**新说法**（价格 / 时效 / 政策）一律要**人工点「采纳进资料库」**才生效 ——
  否则一次性的「这次给你免押」会变成通用政策
* 「学到的」页顶部会一直显示当前开关状态（未开启时是黄色提示）
* 页面上有「预览实际注入给 AI 的内容」——学偏了能一眼看出来

## v1.2 的内容（本版沿用）

### 1. 运营看板（主界面「数据」按钮）

* **今天机器人替我做了什么** —— 接待条数 / 自动解决率 / 待人工 / 中位响应（四张卡）
* **我该补什么资料** —— 常被转人工的问题排行，双击一行直接把客户原话预填进新增资料
* **它有没有乱来** —— 护栏统计（越权承诺 / 议价加码 / 政策未覆盖 / 越界婉拒…各拦下多少）

时间范围支持**今日 / 近 7 天 / 日历自选起止**；可导出 CSV。
第一次打开看板是空的，空状态里有「用示例数据看看效果」——把三批离线评测（共 600 条）
回放成接待记录，客户名全部虚构、不含任何真实数据。

### 2. 界面按开源设计规范重做

依据 [`VoltAgent/awesome-design-md`](https://github.com/VoltAgent/awesome-design-md)
里的 **Stripe** 与 **Linear** 两套规范统一了设计系统（`gui/theme.py`）。

### 3. 界面缩放修正

字号改为**像素字号**、间距走统一缩放因子；窄窗口时头部按钮**自动换行**而不是被裁掉；
看板随窗口宽度等比缩放。

### 4. 设置面板重做 + 接入通道可扩展

* 内容区**可滚动**、窗口**可缩放**
* 「接入通道」不写死三种：**`profiles/` 里任何标定文件都会自动出现在选项里**，
  接钉钉 / 飞书 / 其它软件**不用改代码**

### 5. 自动发门槛 0.55 → 0.50

46 题评测集 42/46（0.55 是 41/46）；三批 600 条 560/600（0.55 是 550/600）；
**两套阈值下"危险直发"都是 0**。

## 测试与评测

* 自动化测试 **1423 个**（含"发错人""内部信号外泄""越权承诺"等事故的回归测试）
* 三套各 200 条测试消息（`eval/messages_200*.csv`），覆盖八大类
* 一键体检：`scripts/eval_messages_200.py`、`threshold_scan.py`、`compare_thresholds.py`

## 运行要求

* Windows 10 / 11 64 位
* 企业微信 PC 版（截图模式）；微信 PC 版需先跑 `scripts/calibrate_chat_app.py` 标定
* 一个 OpenAI 兼容的模型接口（DeepSeek / 通义 / Kimi / 本地 vLLM 皆可）

## 合规说明

* 本程序通过模拟人工操作控制桌面客户端，请确认符合所在平台服务条款与当地法律。
* 客户聊天记录只存在使用者本机 `data/context/`；回答时只把"客户这一句话 + 命中的资料片段"
  发给使用者自己配置的模型接口。
* 分发包里**不含**任何真实客户数据与 API Key；看板示例数据的客户名全部为虚构。

# 想法验证：设置按钮（LLM 接口 + 选择软件）+ 未配置前灰化

**验证日期**：2026-09-24　**结论**：方向对，UI 就这么做没问题；但有 **5 处要改**，
其中 2 处不改会直接翻车（选了微信＝静默不干活；改完设置不生效）。

---

## 一、先说好消息：数据层已经有一半了

「选择软件」这个选项**不需要新造概念**，`config.json` 里已经有两个字段正好对应：

| 你想要的选项 | 现有字段 | 状态 |
|---|---|---|
| 企业微信（**截图**模式） | `channel="screenshot"` + `profile="wecom"` | ✅ 现在正在跑，已端到端验证 |
| 企业微信（**API**模式） | `channel="wecom_api"` + `.env` 三个凭据 | ✅ 代码+本地假服务器端到端验证过，等你凭据 |
| 微信 PC（截图模式） | `profile="wechat_pc"` | ⚠️ profile 还没标定（这台机器没装微信 PC） |

两种模式**共用同一套内核**（RAG / guard / 该不该答 / 待人工队列 / 发送队列都不变），
所以换软件 = 改两个配置字段 + 重启，**不是重写**。设置面板只是给这两个字段做个界面。

## 二、要改的 5 处

### ① 你列的 2 个选项，把唯一验证过能用的那个藏起来了

你写的是「企业微信(api模式) / 微信(截图模式)」。但**你现在跑的就是企业微信截图模式**，
它是这套东西里唯一端到端验证过、正在给你接客户的路径。列表应该是 3 项：

```
○ 企业微信 · 截图模式     ← 默认，现在能用
○ 企业微信 · API 模式      ← 需要填 corp_id / secret / open_kfid
○ 微信 PC · 截图模式       ← 需先装微信 PC 并标定，否则选了等于没开
```

### ② 选了「微信」而微信没装/没登录 → **静默什么都不做**（必须修）

`main.py:363`：

```python
if not scanner.is_running():
    return          # ← 没有 log，界面还写着「状态: 运行中」
```

实测这个分支不产生任何日志。用户会看到界面正常、状态"运行中"，但一条消息都不回，
而且**不知道该怪谁**。灰化按钮挡不住这个（配置是齐的，只是目标软件不在）。
修法：主界面常驻一条状态横幅（`通道 / 目标软件在不在 / LLM 通不通`），不在就红字提示。

### ③ 企业微信 API 确实是每人不同（你猜对了）

`corp_id` / `secret` / `open_kfid` 都是**每家企业自己的**，而且必须先在后台启用「微信客服」。
所以这三项必须让用户填，不能预置。我已经写好了自检，错误会翻成人话：

| errcode | 提示 |
|---|---|
| 40013 | `WECOM_CORP_ID` 不对 |
| 40001 | `WECOM_KF_SECRET` 不对（注意要用【微信客服】那栏的 Secret） |
| 60020 | 调用方 IP 不在企业可信 IP 列表（这台机器出口 IP 是 `203.0.113.10`） |
| — | 没有客服账号 → 去后台创建；`open_kfid` 不在列表里 → 列出可用的 |

### ④ LLM 那"一行"还缺一个「模型名」

`rag/llm_client.py`：

```python
api_key  = os.environ.get("DEEPSEEK_API_KEY")            # 可填
base_url = os.environ.get("DEEPSEEK_BASE_URL", "https://api.deepseek.com/v1")   # 可填
model="deepseek-chat"                                    # ← 写死
```

所以只填地址是不够的：填了通义/Kimi/OpenRouter 的 base_url 会因为**模型名不对**而失败。
建议照 jev 的做法做**预设下拉 + 一键连通测试**：
DeepSeek 官方 / OpenRouter / 通义兼容 / 自定义（自定义时给"地址 + 模型名"两个输入框）。
连通测试就是发一句"请只回复两个字：收到"。

### ⑤ 三个"改完不生效"的坑（不改用户会以为没保存）

| 坑 | 证据 | 后果 |
|---|---|---|
| `channel` / `profile` 只在启动时读一次 | `main.py:88`、`main.py:156` | 换软件后不重启＝白换 |
| `.env` 用 `load_dotenv()`（无 `override`），且 LLM client 缓存在模块全局 | `main.py:38`、`rag/llm_client.py:_client` | 换 API key 后不重启＝还用旧 key |
| `ConfigManager` **只有读没有写** | `config/manager.py` 全文没有 save | 面板存不进去，得新加保存路径 |

修法二选一：设置面板保存后**提示"需重启"并给一个「立即重启」按钮**（最省事），
或者保存时主动 `load_dotenv(override=True)` + 清 `llm_client._client` 缓存 + 重建 channel
（要动的地方多，容易漏）。

## 三、关于"整个界面灰色不可用"

这个做法**目标对、手段建议改**：

* 问题不在于"没配置"，而在于"配置了但用不了"——②和④都是这种。灰化挡不住。
* LLM key 填错时，用户还得能看**日志**和**待人工列表**（那里面有客户消息和 AI 草稿，
  是排查的唯一线索）。全灰化会把人关在门外。
* tkinter 的 `ttk` 里 Button/Entry/Combobox 有 `state=["disabled"]`，
  但 **Label 没有 disabled 状态**，"字体灰色"要一个个改 `foreground` —— 全界面灰化是
  纯手工记账，容易漏（现在代码里一处 `state=` 都没用过）。

**建议的等价做法**：启动时若未配置 → 弹一个**首次配置向导**（Toplevel，必须填完），
主窗口照常显示但处于「未启动」态，顶部挂一条横幅：

```
⚠ 尚未配置：请先填 LLM 接口并选择要接的软件   [去设置]
```

配置齐了但目标软件不在 → 横幅变成：

```
⚠ 通道=微信PC截图，但没找到微信窗口（Weixin.exe）—— 请打开微信并登录   [重试]
```

这样既满足"不配置就不能正常跑"，又保住了排查能力。

## 四、顺带两个必须一起定的细节

1. **API key 存哪**：建议继续写 `.env`（已 gitignore，和 `setup.bat` 的既有流程一致），
   不要写 `config.json`（那个文件是要跟着程序分发的）。明文存储和现在一样，没有变更。
2. **`setup.bat` 要不要留**：它现在做的事就是"复制 .env.example → 打开记事本让你填 key"。
   有了设置面板，这段可以删掉，`setup.bat` 只留"建桌面快捷方式"。

### 实际行为

* 打开程序 → 状态「未启动」+ 黄横幅「未启动。当前：企业微信 · 截图模式。点「开始」运行，或点「设置」重新配置。」

### 顺手修的一个隐患

`settings_store` 原来把路径写成默认参数（`path: os.PathLike = ENV_PATH`）——
默认参数在 `def` 时求值，所以运行时改 `ENV_PATH` 不生效（测试里暴露的）。
改成 `None` + 调用时解析。

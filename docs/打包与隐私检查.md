# 打包与隐私检查（发给别人之前必读）

> 目标：把程序打包成**解压即用**的文件夹发给别人，同时**保证不泄露任何客户数据和密钥**。

---

## 一、结论先看：这个包里有什么、没有什么

| 类别 | 内容 | 发不发 | 为什么 |
|---|---|---|---|
| **程序本体** | `启动.exe` + `_internal/`（Python 运行时、OCR、向量模型） | ✅ 发 | 对方不用装 Python |
| **提示词** | `prompts/*.md`（系统提示、欢迎语、闲聊、占位语、语气样本） | ✅ 发 | 你要求保留；已确认里面**没有**客户姓名/电话 |
| **资料库** | `data/qdrant/`（索引）+ `data/chat_raw/*.txt`（示例资料原文） | ✅ 发 | 你要求保留；是**示例**数据（相机租赁），不是客户对话 |
| **窗口标定** | `profiles/*.json` | ✅ 发 | 不标定对方启动就找不到聊天区 |
| **配置模板** | `config.json`、`.env.example` | ✅ 发 | 只有占位符，没有真值 |
| **使用说明** | `使用说明.txt` | ✅ 发 | 对方照着做就能跑 |
| **真实密钥** | `.env`（LLM Key、企业微信 Secret/Token/AESKey、Redis/Qdrant URL） | ❌ **绝不发** | 发出去等于把 Key 送人 |
| **客户聊天记录** | `data/context/*.jsonl`（客户A、客户B、客户C…） | ❌ **绝不发** | 这是别人的隐私 |
| **运行状态** | `data/state/`（待人工队列、已处理消息）、`data/unanswered.json` | ❌ **绝不发** | 含真实客户原话 |
| **日志** | `logs/`（monitor.log、auto_replies.jsonl、截图） | ❌ **绝不发** | 含客户消息原文与截图 |
| **学到的东西** | `data/learned/`、`data/kb_history.jsonl` | ❌ **绝不发** | 从真实对话里学的 |
| **测试残留** | `data/test_*`、`config.json.bak*` | ❌ **绝不发** | 垃圾 |

## 二、这次审计抓到的真问题（都已修）

| # | 问题 | 后果 | 修法 |
|---|---|---|---|
| 1 | **`WeComBot.spec` 里有 `("data", "data")`** | 会把**整个 data 目录**打进 exe —— 包括 `data/context/` 里 8 份真实客户聊天记录、待人工队列、日志 | 从 spec 删掉这一行（注释里写明禁令）；运行时的 `data/` 改由 `scripts/build.py` 组装，只放白名单内容 |
| 2 | spec 里**没有** `prompts/` 和 `profiles/` | 打包版启动后找不到提示词与窗口标定（在别人电脑上直接不能用） | spec 加 `("prompts","prompts")`、`("profiles","profiles")` |
| 3 | 打包脚本只创建空目录，**资料库是空的** | 对方拿到的是"没有知识的客服" | `build.py` 复制 `data/qdrant/`（索引）+ 示例资料原文 |
| 4 | 没有发布前的自检 | 靠人记得删 `.env`，迟早出事 | 新增 `scripts/privacy_check.py`，**打包流程里强制跑**，不通过就中止 |
| 5 | **设置面板写的 `.env` 落在 `_internal\` 里** | 程序按 CWD 找 exe 同级的 `.env` —— 用户填的 **Key 重启就"没了"**（而且用户根本看不见那个文件） | `config/settings_store.py`：打包后 `ENV_PATH` 指到 **exe 同级目录** |
| 6 | **设置面板写的 `config.json` 也在 `_internal\`** | 程序读的是 exe 同级那份 —— 面板里改了软件选择 / 阈值，**重启就还原** | 同一个 `_app_dir()`：`CONFIG_PATH` 也指 exe 同级 |
| 7 | `启动.bat` 发现没有 `.env` 就**直接退出** | 第一次运行的人会以为"程序坏了" | 改成**自动从 `.env.example` 生成 `.env`**，并提示去设置里填 Key |
| 8 | 隐私自检脚本在 GBK 控制台**打印勾叉时崩了**（假失败） | 打包明明没问题却被中止 | 强制 `stdout` 用 UTF-8 + 去掉 emoji |
| 9 | 自检把整个 `_internal/` 跳过 | 真有泄漏（`_internal/data/context/…`）反而查不出来 | 路径层面全扫，内容层面只跳纯运行时文件 |
| 10 | 仓库文档里有真实凭据 | 如果把仓库当作品集分享，会连企业微信 corp id / Token / 公网 IP 一起发出去 | 见第四节（发布仓库前要清理的清单） |

## 三、怎么打包（一条命令）

```bash
# 1) 先关掉正在运行的程序（否则资料库副本可能不完整）
# 2) 打包
python scripts/build.py
# 3) 产出
dist/WeComBot/          ← 整个文件夹压缩后发给对方
```

打包脚本会依次做 6 件事：
1. 检查/准备本地 BGE 模型（离线可用）
2. 清理旧产物
3. 跑 PyInstaller
4. **组装可分发目录**：白名单方式复制（启动脚本、config、提示词、资料库、标定、使用说明）+ 创建空运行时目录
5. **隐私自检**（`scripts/privacy_check.py`）—— 扫到真实凭据/客户姓名/开发机路径就 **中止打包**
6. 校验必需文件、报告体积

### 单独跑隐私自检

```bash
python scripts/privacy_check.py                      # 检查 dist/WeComBot（默认）
python scripts/privacy_check.py --path .             # 检查整个仓库（发布前）
```

它会查三类东西：
* **不该存在的文件**：`.env`、`data/context`、`data/state`、`data/learned`、
  `data/unanswered.json`、`logs/`、`config.json.bak`、`test_*`
* **不该出现的内容**：`sk-` 开头的真实 Key、企业微信 corp id / Token、
  自己的公网 IP、开发机绝对路径（`D:\<你的项目目录>`、`C:\\Users\\your-name`）、
  真实客户姓名（客户A/客户C/客户D）、手机号
* **二进制里的大文件**：`启动.exe`、`.pyd`、`.dll` 里按字节搜"客户姓名/凭据"——
  防止有人把数据打进包里而文本扫描看不出来

## 四、发布**仓库**（不是包）前还要清的东西

如果你要把这个项目当作品集发给面试官或开源，**仓库里还有几处会泄露**，
它们不在包里，但在仓库里：

| 位置 | 泄露什么 | 怎么办 |
|---|---|---|
| `.env` | LLM API Key、企业微信 Secret / Token / EncodingAESKey | 从仓库删掉（只留 `.env.example`）；如果曾经提交过 git，**要换 Key**（历史里删不干净） |
| `docs/微信客服API接入.md` | 真实 corp id（`wwe0123456789abcd`）、Token、公网 IP、ngrok 域名 | 打码成 `wwe****`、`UfKoc****` |
| `docs/API模式与profile.md`、`docs/想法验证-设置面板与灰化.md`、`docs/知识库使用说明.md` | 公网 IP、开发机绝对路径 `D:\...` | 打码 / 换成相对路径 |
| `docs/superpowers/plans/2026-05-29-wecom-autoreply.md` | corp id、ngrok | 同上（或整个目录不发） |
| `logs/`（含 `univ_chat_223614.png` 聊天截图） | 客户消息原文与截图 | 发布前清空 `logs/` |
| `data/context/`、`data/state/`、`data/unanswered.json` | 客户隐私 | 发布前删掉（程序会自动重建） |
| `docs/面试冲刺/` | 你自己的面试准备材料 | 按需（当作品集时建议删掉） |
| `config.json.bak*`、`setup.bat.bak`、`启动.bat.bak` | 旧配置（可能含旧凭据） | 删掉 |

> 一句话：**`privacy_check.py --path .` 跑一遍，把报出来的都处理掉再发仓库。**
> 它现在会报 `.env`、`config.json.bak*`、`logs/*`、`data/context/*`、
> `data/state/*`、`data/unanswered.json` 和文档里的凭据。

## 五、对方拿到包之后怎么用（已写进 `使用说明.txt`）

1. 解压 → 双击 `启动.bat`
2. 「设置」里填**他自己的**模型 API Key（不填也能开，但只会转人工）
3. 选「企业微信 · 截图模式」，登录企业微信 PC 版
4. 点「开始」
5. 换成自己的资料：知识库 → 资料库 → 上传 → 重建索引

隐私口径（可以照抄给对方）：
> 客户聊天记录只存在本机 `data/context/`，程序不上传；
> 回答时会调用**你自己配置的**模型接口，发送内容是"客户这一句话 + 命中的资料片段"；
> 不配 API Key 就完全不外发内容。

## 六、还没做（已知）

* **没有在另一台电脑上真机验证过**：包结构与路径已按"运行时 CWD 相对路径"设计并自检，
  但"换台机器能不能跑"只能真机验证。建议第一次发人时让对方按 `使用说明.txt`
  走一遍，并让他把 `logs/monitor.log` 发回来。
* **包体约 3GB**（Python 运行时 + torch + OCR + 向量模型）。
  如果嫌大：把 `PaddleOCR` 这条回退链去掉（当前默认是 RapidOCR/ONNX），能省 1GB 左右 ——
  属于改代码，等你说要动再做。
* **UPX 压缩**：spec 里开着 `upx=True`，但机器上没装 UPX 时 PyInstaller 会跳过（不影响运行）。

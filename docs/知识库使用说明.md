# 客服知识库使用说明

摄影器材租赁网店的客服知识库，供「企业微信智能客服」自动回复使用。

- **知识块**：231 条（14 个文件）
- **向量库**：`data/qdrant`（204 → 231 维 512，Cosine）
- **源文件**：`data/chat_raw/*.txt`（企业微信 PC 端复制格式，UTF-8）

## 改价格 / 加问答

**不要直接改 `data/chat_raw/*.txt`** —— 那些是生成出来的。改 `scripts/gen_kb.py`：

```python
# 改价格：改这个列表
BODIES = [
    ("索尼 A7M4", 90, 4000, "3300 万像素，4K 60 帧，五轴防抖，最热门的全能机型"),
    #            ↑日租 ↑押金  ↑说明
]

# 加 FAQ：主题名, [客户问法...], 答案
FAQS = [
    ("起租天数",
     ["最少租几天", "起租天数是多少", "可以只租一天吗"],
     "起租 3 天，也就是最短按 3 天计费。"),
]
```

然后：

```powershell
cd D:\\your-project
.venv\Scripts\python.exe scripts\gen_kb.py                  # 生成 + 自检
.venv\Scripts\python.exe scripts\run_local.py --skip-videos --clean   # 重建向量库
```

**`--clean` 必须加。** `pipeline/embedder.py` 只做 upsert、从不删除，不清空的话旧价格
会和新价格同时被检索到（实测：改价后"日租 80 元"和"日租 90 元"两个 chunk 都会命中，
模型可能报错价格）。

## 三条必须遵守的规则

生成器已内置校验，违反会直接报错退出。

**1. 答案里出现的每个数字都要写在答案里**

`rag/guard.py` 会拦截"回复中 ≥30% 的数字不在知识片段里"的情况（防编造价格）。
所以金额、天数、折扣、百分比都必须落在答案文本中。

**2. 答案不能用这些措辞**（会被判 block 或降级，永远进不了自动发送）

- 不确定词：`我不确定`、`我不太确定`、`可能`、`也许`、`大概`、`据我所知`、`我不是很了解`、`建议咨询`、`请咨询`、`详情请咨询`、`这个我不清楚`、`抱歉我不太清楚`、`或许可以`、`可能需要`、`您可以试试`
- 套话：`请问有什么可以帮您`、`很高兴为您服务`、`我是销售客服`、`请问您想了解什么` 等 9 条
- 模糊话术：`具体价格请咨询`、`详情请联系`、`以实际为准`、`具体请咨询`、`最终价格以`、`请联系客服`、`以上仅供参考`

⚠️ `可能` 是**子串匹配** —— "可能是 3 天"会被拦。

**3. 客户问法至少 4 个字**

`pipeline/chat_importer.py` 的 `MIN_QUESTION_LEN = 4`，短于 4 字会被静默丢弃
（"价格表"、"包邮吗"就是这么丢的）。

## 分流规则（二档）

| 条件 | 结果 |
| --- | --- |
| 检索分数 **> 0.65** 且 guard 不拦 | **直接发给客户** |
| 检索分数 ≤ 0.65，或 guard 拦下（含封禁词/编造数字） | **转人工**：① 弹窗通知你 ② 自动给客户回一句礼貌占位语 |
| 检索分数 < 0.4 或无结果 | 同上（且不调用 LLM，省 token） |

门槛在 `config.json` 的 `rag.high_confidence_threshold`（改完需重启）。

「人工确认」中间档已取消 —— 不再有需要你手动点发送的待处理列表。
转人工时自动发给客户的占位语定义在 `rag/responder.py` 的 `HOLD_REPLIES`
（三句随机挑，措辞已校验不含 guard 封禁词）。

分数取决于**客户实际问法**和库里问法的相似度。想提高直接发送率，就给每个
主题多写几条客户问法（各条独立成一对，答案会重复，这是有意的 —— 为了覆盖
不同措辞）。

## 已知局限

- 库里的问法是我推测的措辞。**真实客户的说法可能不在库里** → 分数低于 0.7 → 进待处理。
  跑一段时间后看 `logs/auto_replies.jsonl` 里 `dispatch_level` 的分布，把常问但没命中的
  问法补进 `gen_kb.py`。
- 超范围问题（"能不能帮我P图"）会落到某个不相干的 chunk 上，分数约 0.4~0.5 →
  进人工确认。LLM 看到片段不覆盖问题会回"需要人工处理"，这是设计行为。
- 价格、押金、电话、地址全是我编的占位数据，**上线前必须换成真实信息**。

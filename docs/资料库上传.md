# 资料库上传：支持哪些格式、为什么这么切块

对应代码：`pipeline/upload.py`，界面在 `gui/kb_dialog.py` 的「资料库」页。

## 支持 / 不支持

| 格式 | 读法 | 备注 |
|---|---|---|
| `.txt` `.md` | 文本，编码试 utf-8-sig → utf-8 → gbk → gb18030 | 交给通用切块器（500 字/块） |
| `.csv` | 标准库 csv | 按行切块 |
| `.xlsx` `.xlsm` | openpyxl，`read_only=True` | 按行切块，多工作表带表名 |
| `.xls` | xlrd | 同上，日期按 xldate 还原 |
| `.docx` | python-docx | 段落按语义切 + 表格按行切 |
| `.doc` `.wps` | **不读** | OLE 二进制，没有可靠的纯 Python 读法。报错提示用户「另存为 .docx」，比读出乱码喂给 LLM 强 |

一张表超过 `MAX_TABLE_ROWS = 5000` 行直接报错，不静默截断 —— 半份价目表比没有更危险。

## 三条设计原则

1. **源留原文件，不留解析后的文本。**
   上传的文件**原样字节复制**到 `data/chat_raw/uploaded/`（xlsx 还是 xlsx）。
   如果存"解析后的文本"，点「重建索引」重新解析时表格结构就没了，切块方式跟着变、
   检索质量静默下降，用户完全不会知道。索引可再生，源才是资产。

2. **一行一块，块里带表名，并给租期表头补同义词。**
   整张表嵌成一块时问句被几十行无关内容稀释。实测（bge-small-zh，余弦）：

   | 写法 | 「索尼A7M4一天多少钱」 |
   |---|---|
   | 整张表一块（pipe 表格） | 0.63 ← 够不到 0.65 直发门槛，有资料也转人工 |
   | `器材 日租 押金 ⏎ 索尼A7M4 120 2000` | 0.68 |
   | `索尼A7M4：日租 120，押金 2000` | 0.75 |

   但只有 0.75 还不够 —— 库里同时有「周租 600」时，**问"一天多少钱"会被周租那块抢到第一**。
   给租期表头补上客户嘴里的说法（`日租（一天）`、`周租（一周）`、`月租（一个月）`）后，
   日/周/月各归各位（差距 +0.04 ~ +0.08）。这只是把表头换个说法，**不添加数据里没有的价格或单位**。

3. **重传同名文件＝替换，不是叠加。**
   老板改了价目表再传一次，如果只往后加，库里就同时有新旧两份价格，检索可能命中旧的
   —— 机器人报错价，比不回答严重。所以：
   - 旧源挪到 `uploaded/.old/<名>_<时间戳>.<后缀>`（不删，换错了能捞回来）
   - 按 `payload.source` 删掉旧向量
   - 删除失败时进度里提示「建议点重建索引」，不假装成功
   - 同一批里两个不同目录的同名文件**不**互相顶掉，加 `_1` 后缀共存

## 重建索引

`source_files()` = `data/chat_raw/*.txt`（老的视频/FAQ 源）+ `uploaded/` 下所有支持格式。
重建前会二次确认，然后清空 collection 重新嵌入。

⚠️ 重建时**绝不能**再走 `replace_source` —— 那会把源当"重传"挪进 `.old/`，
等于一边重建一边把源删了。`already_home()` 负责认出"这文件本来就在源目录里"，
直接用它、不复制、不备份。回归测试：`tests/test_upload.py::test_rebuild_does_not_touch_sources`。

## 表格行怎么变成一句话

```
表头: 器材 | 日租 | 押金 | 备注
数据: 索尼A7M4 | 120 | 2000 | 含24-70
块:   【日租】索尼A7M4：日租（一天）120，押金 2000，备注 含24-70
```

- 第一格当主语，其余按「表头 值」拼，全角逗号连接
- 某列空掉的行（备注常为空）**按原列号对表头**，不会整体错位成 `佳能R5，150，3000`
- 第一行是否当表头，看「所有格都 ≤8 字且不含数字」；没有表头的表按整行逗号拼接
- 多工作表 / 多表格在块前加 `【表名】`，避免日租和周租串味

## 依赖

`openpyxl==3.1.5`、`xlrd==2.0.2`、`python-docx==1.2.0`（已写进 requirements.txt）。
都是纯 Python，PyInstaller 静态分析能直接收到，不用额外 hiddenimports。

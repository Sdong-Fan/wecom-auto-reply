# 示例知识库（相机租赁）

这 14 个 txt 是**虚构的**一家相机租赁店的业务资料（价格、押金、租期、配送、发票、损坏赔付…），
用来演示"把业务资料丢进知识库 → 机器人照着答"。

怎么用：

1. 启动程序 → 界面「知识库」→「资料库」→「选择文件…」→ 选中本目录里的 txt
2. 点「重建索引」（首次要加载嵌入模型，约 10~30 秒）
3. 到「试问一句」里问：`索尼 A7M4 日租多少钱`、`可以免押金吗`、`坏了要赔吗`
4. 想看机器人怎么处理答不上来的问题：「最常转人工的问题」那个按钮

说明：

* 资料是**虚构示例**，不含任何真实客户信息与真实商家数据。
* 想让机器人答你自己的业务，就换成你自己的资料（支持 txt / md / csv / Excel / Word）。
* 机器人只按资料回答，资料里没有的价格/政策它会转人工，不会瞎编
  —— 这正是这个项目的核心设计（见 `docs/` 里的设计文档）。

产品演示（2 分 22 秒）

演示内容：填模型接口 → 上传业务资料 → 看板看它今天做了什么 → 客户问「索尼 zve10 多少钱」它按资料库直接答。

1.5 秒首次响应中位（人工客服通常几十秒起）
93.3%三批 600 条离线测试行为符合（560/600）
0 次"该转人工却发出去" & 报错价
1647自动化测试（含 4 次事故回归）

一句话

  • 给"一个人兼客服的 1–5 人小店"做一套不用改代码就能接入的自动客服： 截屏读企业微信消息，只按店主自己上传的资料回答；资料答得出来就按资料答， 答不出来才转人工，人工改稿确认后它还会学。

问题（为什么要做）

  • 小店老板绝大多数咨询是重复的：实测真实客户消息 99%（76/77）集中在 7 类问题上 （押金/免押、营业时间、机型库存、租赁规则等）。
  • 通用客服 SaaS 要么要企业认证 + 开发对接，要么按坐席收费（同类产品客服名额约 550 元/客服/年）—— 对一个人看店的小店都不成立。
  • 结果：老板一边干活一边手打回复，响应慢一点就丢单。

目标用户

  • 第一优先：1–5 人、店主本人兼客服的小店/工作室（无 IT 支持、拿不到 API 权限、 问题重复且答案固定）。
  • 不做：中大型企业 —— 他们要权限、审计、SLA，选型逻辑完全不同。

产品与链路

  • 形态：装在本机 Windows 上的桌面端自动客服（不改客户端、不要 API 资质、免安装）。
  • 链路：截屏识别新消息 → 先查店主自己的资料库（命中够高就以资料库为准）→ 查不到才判"该不该答"（规则层；规则拿不准的模糊句子问一次模型仲裁）→ 业务问题且资料库没有 → 转人工；闲聊 → 直接生成回复 → 三态质量门控（直发 / 降级 / 转人工）→ 待人工工作台改稿后学习 → "最常转人工的问题"排行回流指导补资料，形成闭环。
  • 四条关键机制：
    ① 回复中的价格与型号必须在资料库中有出处，否则拦下转人工；
    ② 资料库优先于规则层：规则层判了"转人工"、但资料库答得出来（最高分 ≥ 0.75）时， 改成按资料库回答 —— 只对政策类原因生效，实时状态（快递到哪了、有没有现货）、 权限（议价、退款、投诉）、安全（伪造、要他人信息）仍一律转人工；
    ③ 越界请求（套取凭据、背诗、算长算式）按模板婉拒；
    ④ 发送前确认会话名防发错人。

现在能做什么（v1.3）

  • 只按你的资料回答：资料答得出来就答（资料库优先），答不出来转人工，并给客户一句礼貌的占位语。
  • 待人工工作台：答不准的一条一行，可改稿后再发；改稿可选让它学。
  • 「已回复」流水：软件所有发出去的消息（自动回复 / 占位语 / 欢迎语 / 人工代发） 带时间落表，重启不丢 —— 店主能一眼看到"它到底替我发了什么"。
  • 从改稿里学（默认开启）：学到的东西先进「学到的」等你确认，不自动进资料库； 确认进库的会合并成一条完整事实，并用"客户会怎么问"当检索面。
  • 资料导入：上传 txt / md / csv / Excel / Word；陈述句和表格可以用 「用 AI 整理成问答」拆成一问一答，数字与型号自动校验（对不上的标红）， 人工勾选后才写入。
  • 资料库：多档案互不影响，全库搜索，上一页/下一页真翻页；提示词（系统提示、欢迎语、 闲聊、占位语）界面里可改，改完立即生效。
  • 不打扰：窗口置顶可配置（默认不置顶）；聊天记录只留在本机。

我的角色

  • 本项目基于开源项目 zhu-tingshuai/personal_wxwork_ZTS（MIT 许可）改造： 采集层（截图 / 红点 / 气泡 / OCR）与界面框架来自上游，原始版权声明按 MIT 要求完整保留。
  • 我负责的五块：① 定义"什么时候不能答"并落地护栏；② 建立评测与指标体系（46 题评测集 + 阈值扫描）； ③ 设计人机学习闭环；④ 发送链路安全；⑤ 交付与隐私（打包隐私门禁、免安装分发）。
  • 最近一版又补了三块：⑥ 重排判断顺序（资料库优先于规则层，门槛用扫描定在 0.75）； ⑦ 模糊地带交给模型仲裁（只在 1% 的句子上触发，失败就退回规则）； ⑧ 「用 AI 整理成问答」导入（陈述句/表格 → 问答对，带数字与型号校验）。

怎么自己跑（3 步）

  1. 解压免安装包（Windows，下载约 850 MB，解压后约 1.6 GB）→ 双击 启动.bat（首次启动加载模型约 30–90 秒）
  2. 界面右上「设置」→ 填你自己的模型接口（API Key / 地址 / 模型名）→ 保存
  3. 选「企业微信 · 截图模式」→ 打开企业微信 PC 版并登录 → 点「开始」

没配模型接口点「开始」会被拦下（弹窗送到「设置」）：没接口时它答不了业务问题， 却仍会给客户回一句"稍等我确认一下"，等于替老板许了个空头承诺。程序默认就是「未启动」。
